Générateur de description

Un produit, ses points forts : une description courte et une version détaillée à copier.

Que mettre dans une bonne description ?

Une bonne description répond à trois questions : c'est quoi, pour qui, et pourquoi le choisir. Liste des points forts concrets (matière, dimensions, durée de vie, garantie) plutôt que des adjectifs vagues.

Pour vendre un vêtement ou un objet d'occasion sur Vinted, utilise plutôt le générateur de description Vinted, adapté à ce format.
