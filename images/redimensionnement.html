Comment garder les bonnes proportions ?

Quand tu changes la largeur, la hauteur s'adapte automatiquement (et inversement) pour que l'image ne soit pas déformée. Les boutons de pourcentage réduisent les deux côtés dans la même proportion.

Réduire une image donne un bon résultat ; l'agrandir la rend floue, car les pixels manquants sont devinés. Pour le web, une largeur de 1200 à 1600 px suffit presque toujours.
